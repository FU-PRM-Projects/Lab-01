# PaperChat native package

This local Windows FFI plugin owns the Rust crate and all generated bindings. The package/crate name remains `lab_05_rust` so the DLL name stays stable.

- `lib/paper_native.dart`: public entry point (`initializeNative`, PDF and vector types).
- `rust/src/api/pdf_parser.rs`: `pdf-inspector` extraction and page-aware chunking.
- `rust/src/api/vector_index.rs`: exact cosine search, `itertools` top-k selection, and compatible TVEC persistence.
- `lib/src/rust/` and `rust/src/frb_generated.rs`: generated by flutter_rust_bridge.
- `windows/`: Cargokit wiring, using the package location rather than a fixed number of parent directories.
- `cargokit/`: upstream vendored build support. Retain its scripts and license together; it is not application code.

## Regenerate the bridge

From the repository root, with Flutter/Dart and Cargo on PATH:

```powershell
cargo install flutter_rust_bridge_codegen --version 2.13.0 --locked
Push-Location packages/paper_native
try {
  flutter pub get
  flutter_rust_bridge_codegen generate
} finally {
  Pop-Location
}
```

The Rust dependency, Dart dependency, and generator are pinned to **2.13.0**. The config uses Dart `int` for the Windows bridge, eliminating application-side BigInt and Uint64 buffer conversions. Regeneration may emit conditional web files; only Windows is registered as a supported plugin platform.

Normal Flutter builds compile and bundle Rust automatically. For Flutter native service tests, build the standalone DLL first:

```powershell
cargo build --release --locked --manifest-path packages/paper_native/rust/Cargo.toml
flutter test --tags native
```

The native test loader accepts `--dart-define=NATIVE_LIBRARY=<absolute DLL path>` to verify a packaged copy. Production initialization loads the bundled DLL using the generated bridge loader.

References: [flutter_rust_bridge/Cargokit](https://cjycode.com/flutter_rust_bridge/manual/integrate/cargokit), [itertools top-k API](https://docs.rs/itertools/latest/itertools/trait.Itertools.html#method.k_smallest_by).
